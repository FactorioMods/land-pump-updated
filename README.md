# Land Pump: Updated

Allows offshore pumps to draw the planet’s tile fluid from naturally generated land. Existing per-planet startup choices remain available.

This Factorio 2.1 port fixes the independent planet switches: disabling one planet, encountering a missing tile or finding a planet without tile generation settings no longer stops processing the others. It requires Factorio 2.1.24 or later.

Original project: [Land-Pump](https://mods.factorio.com/mod/Land-Pump) — MonoToast. [Updated Mod Portal page](https://mods.factorio.com/mod/land-pump-updated) · [Fork source](https://github.com/FactorioMods/land-pump-updated).
